# llm-proxy

Статус: не реализован; каталог предусмотрен шаблоном курса.

Будет единственной точкой обращения к API модели: ключ хранится в этом сервисе
и не попадает в сандбокс. Адрес модели, её версия и конфигурация фиксируются для эксперимента.
Переменные `LLM_PROVIDER_URL` и `LLM_API_KEY` пока только описаны в `.env.example`.

Исходники и Dockerfile появятся здесь. Задача C1-02 — в [TASKS.md](../../TASKS.md).
