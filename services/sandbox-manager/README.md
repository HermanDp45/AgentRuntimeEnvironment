# sandbox-manager

Статус: не реализован; каталог предусмотрен шаблоном курса.

Будет создавать сандбокс, исполнять команды, собирать результаты, отменять операции
и освобождать ресурсы. Лимиты CPU, RAM, PIDs, диска и времени должны проверяться тестами.
Выбор способа запуска требует ADR с разбором прав, включая риск доступа к Docker socket.

Исходники и Dockerfile появятся здесь. Контракт — [contracts/](../../contracts/README.md).
Задачи C1-04 и C2-03 — в [TASKS.md](../../TASKS.md).
