# БАФ — базисные агентские функции

Проверяют атомарные функции пары «харнес + LLM»: чтение, поиск, создание,
редактирование, инструмент, код, рассуждение, синтез. Инфраструктура проверяется
отдельно в [tests/infra/](../tests/infra/README.md).

Курсовой набор — [catalog.yaml](catalog.yaml): 8 БАФ × 3 задачи + 3 составные.
Ранний набор содержит пять простых задач Б1–Б5. Каталог, фикстура и чекер Б1.1
взяты из [ревизии курса b01ddf7](https://github.com/deeppavlov/agentic-course-itmo/tree/b01ddf7b89e5c603985e3d5b5af958bebc7b1972/projects/templates/track-a-agent-runtime/baf).
В Б1.1 уточнён путь к конфигу и инструмент чтения. Фикстуры Б2.1–Б5.1 реализованы
по заданиям каталога. Средние задачи, подвохи и собственный набор ещё впереди.

## Формат задачи

```text
baf/<БАФ>/<задача>/
├── task.yaml    # id, baf, level, messages, timeout_s, answer_file
├── fixture/     # исходное содержимое workdir
└── check.py     # итоговое состояние → JSON {"pass": bool, "reason": str}
```

Каждый запуск начинает с чистой копии fixture. Чекер и скрытые эталоны находятся
вне рабочей папки агента. Чекер проверяет итоговый файл. Для Б2.1 и Б5.1 раннер также проверяет успешное выполнение команды.
Успех определяется JSON-полем `pass`: чекер Б1.1 возвращает exit code 0 и при неверном ответе.

## Ранний прогон

Из корня репозитория с настроенной моделью в локальном .env:

```bash
make setup
make up
make baf-early
```

Для другого адреса и токена gateway задайте CLIENT_TOKEN и передайте
`BAF_ARGS='--url http://127.0.0.1:8080'`. Можно выбрать отдельные задачи флагом
`--task B1.1` или новый путь к JSONL флагом `--output` через BAF_ARGS.

Раннер использует существующий gateway v0. Для каждой задачи создаёт чистую сессию,
отправляет сообщение и слушает SSE. В этой сессии он разрешает запись только в
answer_file и только точную команду из task.yaml, если она указана. Для остальных
запросов посылает отказ. Затем получает файлы, запускает чекер и закрывает сессию,
в том числе при обрыве. Чат и CLI сохраняют ручные подтверждения.

По умолчанию запись идёт в `results/baf/early/<timestamp>.jsonl`. В каждой строке
есть задача, вердикт, причина, модель из событий, токены, время, run_id и решения
по подтверждениям. Команда возвращает код 1, если хотя бы одна задача не прошла.
[Первый технический прогон](../results/2026-11-10-baf-early/README.md).

Полный offline smoke по всем восьми БАФ и бенчмарк с повторами и сравнением пар
остаются отдельными задачами. Цели `make baf-smoke` и `make baf` пока недоступны.

Чекер Б1.1 можно вызвать отдельно: `uv run --frozen --offline python
baf/B1-read/B1.1-service-port/check.py /путь/к/итоговой/папке`.
Это проверка файла, не запуск агента и не доказательство прохождения БАФ.
