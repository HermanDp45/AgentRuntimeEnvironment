Даты допустимы только ISO ГГГГ-ММ-ДД. Дату с / считай неоднозначной (ambiguous_date), отрицательное quantity ошибкой negative_quantity. Номер row — строка CSV с заголовком на строке 1. Ошибочные строки не включай в rows.
Запиши result.json: объект с ровно двумя ключами rows (массив нормализованных объектов) и errors (массив ошибок row/field/code). Сохрани порядок строк. При отсутствии ошибок errors пустой. Исходный CSV не изменяй.
