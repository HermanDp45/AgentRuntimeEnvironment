# Клиент

Работают базовый чат на PySide6 и консольный сценарий. Оба используют gateway,
а не запускают команды на Mac. Сетевой экспорт учебной папки можно проверить отдельно
в [эксперименте с WebDAV](../docs/workdir-demo.md).

## Окно чата

Оформление следует светлой или тёмной теме системы. Переписка и ввод слева,
действия и файлы справа. Перед подтверждением изменения выделены цветом,
а подсказка под полем ввода показывает сочетание клавиш для отправки.

После make setup и make up:

```bash
make setup-gui
make gui
```

Нажми «Выбрать папку…», выбери каталог и нажми «Подключить чат». Во вкладке
«Файлы» появятся текстовые файлы каталога. Для проверки создай в нём note.txt
с текстом original и отправь «Прочитай note.txt и замени original на changed».
Перед записью появится diff. После разрешения файл изменится на диске.
Кнопка «Обновить файлы» под списком показывает изменения из Finder.

Служебные файлы .git и .env скрыты. Симлинки и жёсткие ссылки не экспортируются.
Команды читают /work, а для правок модель использует write_file. Ограничения
просмотра — до 128 текстовых файлов, каждый до 64 КиБ.

Если подключиться без выбора папки, будет создана прежняя учебная фикстура.
«Отклонить» возвращает отказ модели. «Отмена» сохраняет завершённые правки.

Следующие сообщения продолжают ту же сессию. Файлы обновляются после завершения задачи.
Ответы модели показываются целиком; stdout/stderr команд поступает событиями.
Отправка — кнопкой или Cmd+Enter на Mac, Ctrl+Enter на Linux.

Закрытие окна освобождает сессию. Выбранная папка сохраняется.
Учебная фикстура удаляется. Если сервер не подтвердил закрытие,
появится ошибка; закрытие можно повторить. При обрыве SSE клиент возобновляет GET
с последнего события до трёх раз; задача и команды заново не отправляются.
После потери сервера/перезапуска приложения восстановления сессии пока нет.
Экспорт выбранной папки останавливается после закрытия сессии.
Подключение проверено на macOS и Docker Desktop. На Linux используется тот же POSIX-код.
Для Windows и удалённого сервера интеграция ещё предстоит.

Другой сервер:

```bash
uv run --frozen --offline --group gui python -m client.gui --url http://127.0.0.1:8080
```

Qt Essentials установлен только в группе gui. Сервер и CLI работают без Qt.
Код: gui.py — окно и фоновые запросы, api.py — общий транспорт, cli.py — консоль.

## Ручной запуск

После make setup и make up из корня репозитория:

```bash
uv run --frozen --offline python -m client.cli
```

Клиент создаёт временную учебную сессию с note.txt, содержащим original.
Задача по умолчанию — прочитать его и заменить текст на changed.
Для записи показывается diff, для команды — её точный текст. y/да разрешает действие,
остальные ответы запрещают. Ctrl+C отменяет запуск; готовые изменения не откатываются.
В конце выводятся результат и файлы, затем сессия закрывается и фикстура удаляется.

Другой адрес и задача:

```bash
uv run --frozen --offline python -m client.cli --url http://127.0.0.1:8080 --task "Прочитай note.txt"
```

Токен клиента берётся из CLIENT_TOKEN; локальное значение по умолчанию — local-dev-token.
Он должен совпадать с одним из CLIENT_TOKENS сервера. API-ключ модели клиенту не нужен.
Серверный LLM-прокси нужно отдельно настроить через .env для реального API.

## Проверка без API

```bash
make up-test
CLIENT_TOKEN=fixture-client-token uv run --frozen --offline python -m client.cli --url http://127.0.0.1:18080 --task test:edit
make test-agent
make down-test
```

test:edit — сценарий только тестового стенда: чтение, запись и команда с exit 1.
Реальная модель в нём не вызывается. Автотест запускает этот же клиент с двумя
ответами y и проверяет diff, подтверждения и результат.

Повторное сообщение и восстановление SSE поддерживаются серверным API;
автоматического переподключения и продолжительного чата в этом CLI пока нет.
GUI уже использует тот же контракт; полный headless-режим ещё не реализован.

Для GUI с тестовой моделью после make setup-gui и make up-test:

```bash
CLIENT_TOKEN=fixture-client-token uv run --frozen --offline --group gui python -m client.gui --url http://127.0.0.1:18080
```

Отправьте test:edit: появятся два подтверждения, затем изменённый файл и вывод команды.
Автопроверки — make test-ui; [подробности](../tests/ui/README.md).
