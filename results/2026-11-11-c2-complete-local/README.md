# Полный локальный набор ЧП2

Дата: 2026-11-11. Проверяющий: агент. macOS arm64, Docker Desktop.
Реальная модель не вызывается: fixture-model возвращает подготовленные сценарные
ответы. Это проверка среды и БАФ-набора, не результат качества пары.

## Команды

```bash
make setup-gui
make test-ci
make up-test
BAF_ARGS='--suite full --mount --repeat 3 --output results/2026-11-11-c2-complete-local/verified-replay.jsonl' make baf-smoke
make down-test
make build-client
QT_QPA_PLATFORM=offscreen dist/AgentRuntime.app/Contents/MacOS/AgentRuntime --smoke-test
```

При повторном запуске выберите новое имя output. Раннер сохраняет JSONL и
.manifest.json с хешами входов, включая общий код чекеров и серверных компонентов.
Исходные материалы фиксируются в репозитории; секретов и пользовательских файлов нет.

## Что проверяется

- 39 задач: 24 курсовые атомарные, 3 курсовые составные, 8 своих вариантов,
  3 задачи Б9 и своя C4. Каждый повтор получает новую временную папку и сессию.
- Б2.2: поиск 12 обращений к DB_URL среди 200 файлов через mount.
- Б4.3: точная замена цены в cp1251 с сохранением CRLF и остальных байтов.
- Б5.2/Б5.3: обязательное исполнение команд с ожидаемым exit 1.
- Скрытые тесты кода выполняются отдельно в сандбоксе. C3 дополнительно проверяет,
  что тесты кандидата отвергают сломанную утилиту.
- SIGKILL харнеса после подтверждённого старта команды: менеджер останавливает её
  по таймауту, потомков нет, завершённая запись сохранена; после рестарта run потерян.
- Собранное приложение создаёт окно Qt и штатно закрывается в offscreen-режиме.
  Это проверка загрузки пакета, сетевые сценарии покрываются отдельно QtTest.

## Промежуточный прогон

full-replay.jsonl — промежуточные 117 попыток. Во время этого запуска уточнялись
формулировки поиска файлов и C3, а образ mock содержал предыдущий replay.
Ошибки несовпадения сценариев в нём не являются оценкой модели или итогом набора.
Итоговым считается отдельный verified-replay.jsonl после пересборки.
