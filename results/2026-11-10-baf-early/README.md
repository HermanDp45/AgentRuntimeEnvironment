# Первые Б1–Б5 через gateway

Дата: 2026-11-10. Проверял агент. Среда: macOS arm64, Python 3.13.15,
Docker Engine 27.3.1, основной Compose и собственный харнес. Модель:
`Qwen/Qwen3-235B-A22B-Instruct-2507` через `https://inference.airi.net`.
Один повтор каждой простой задачи. Все сессии используют синтетические файлы.

```bash
make setup
make up
make baf-early BAF_ARGS='--output results/baf/early/reproduction.jsonl'
```

Для повтора нужны указанные URL и модель в .env и локальный токен провайдера.
Конфигурация сандбокса и харнеса хранится в config.toml соответствующих сервисов.
Фикстуры, разрешённые операции и чекеры находятся в baf/.

- [Первый прогон](airi-qwen-initial.jsonl) — 4/5. Б1.1 завершилась без answer.txt:
  модель трижды запросила shell-команды, которых не было в разрешениях задачи.
  Для воспроизведения первоначальной формулировки берётся первый элемент messages
  из текущего task.yaml Б1.1.
- [Повторный прогон](airi-qwen.jsonl) — 5/5. В Б1.1 добавили явное чтение
  config/app.yaml через read_file. Остальные задачи и политика разрешений те же.
  Б2.1 и Б5.1 включают подтверждение точной команды и проверку её exit code.
- [Локальные тесты](test-ci.txt) — unit/UI без запросов к модели и проверка lock/Ruff.
  Docker-тесты без указания стенда пропускаются.
- [Тесты Compose](infra.txt) — `make up-test`, `make test-agent`, `make down-test`.
  Девять сценариев прошли с mock LLM после пересборки по новому lock-файлу.

Это технический прогон раннера. Для курсовой оценки остаётся повторить его на
разрешённой модели. Каталог AIRI с текущим токеном 10 ноября вернул
`Openai/Gpt-oss-120b`, `Qwen/Qwen3-235B-A22B-Instruct-2507` и `Qwen/Qwen3.8-27B`.
