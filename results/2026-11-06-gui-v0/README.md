# Базовый чат v0 — 2026-11-06

Среда: macOS arm64, Python 3.13.15, PySide6 Essentials 6.10.1, uv 0.12.12,
Docker Desktop 4.36.0 / Engine 27.3.1 / Compose 2.30.3. Проверял агент.
Человеческая проверка пока не заявлена.

## Воспроизведение

```bash
make setup
make setup-gui
make test-ci
make up-test
HARNESS_TEST_URL=http://127.0.0.1:18080 make test-ui
make test-agent
make down-test
```

После установки и сборки тесты не используют внешние сервисы или реальную модель.
Compose — корневой docker-compose.yml + tests/infra/compose.yml, проект are-offline;
в тестовом llm-proxy закреплён mock URL. Текущие версии и зависимости — в uv.lock,
сценарий модели — services/llm-proxy/testing/mock_llm.py. Контейнеры сервера собраны
с новым lock-файлом; Qt в них не устанавливается.

## Результат

- [test-ci.txt](test-ci.txt): lock/Ruff/форматирование и локальные тесты;
  Docker-сценарии и дополнительный UI-тест Compose пропущены без переменных стенда.

  с gateway и Docker-сандбокс. Два отдельных подтверждения, diff, вывод команды с exit 1,
  содержимое изменённого файла, завершение и закрытие сессии.
- Остальные UI-сценарии выполняются против mock HTTP/SSE-транспорта: запрет записи
  до решения, отказ, история двух сообщений, отмена, возобновление потока без повторного
  task, потеря ответа POST, неверный токен и повтор закрытия после HTTP 503.
- [infra.txt](infra.txt): все 9 существующих тестов Docker/харнеса/CLI прошли.
- [cleanup.txt](cleanup.txt): тестовый Compose удалён; список оставшихся сандбоксов
  are.owner=are-offline пуст.
- [chat.png](chat.png): снимок самого окна в offscreen-режиме после синтетического test:edit.
