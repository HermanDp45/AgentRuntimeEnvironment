# Выбранная папка в настольном чате

Дата 2026-11-11. Агент проверил macOS arm64, Docker Desktop, Python 3.13.15,
PySide6 Essentials 6.10.1 и rclone 1.75.2. Тег и digest помощника закреплены
в коде. Использовались временные каталоги с синтетическими файлами.

```bash
make setup-gui
make test-ci
make up-test
HARNESS_TEST_URL=http://127.0.0.1:18080 make test-ui
make test-agent
make down-test
```

Для прогона выбранной папки нужен образ rclone, который устанавливает
`make up`. Для отдельной загрузки используется digest WORKDIR_IMAGE из Makefile.
Qt-тест вызывает штатные кнопки, подставляя временный путь в диалог выбора.
Он проверяет показ исходного файла, подтверждение правки, запись на Mac,
обновление после локальной правки, запрет записи shell-командой и сохранение
файла после закрытия окна. Mock LLM работает внутри отдельного Compose.

- [test-ci.txt](test-ci.txt) — 55 прошли, 11 пропущены без Compose.
- [ui-compose.txt](ui-compose.txt) — 9 тестов прошли, включая реальный выбор папки.
- [infra.txt](infra.txt) — 9 существующих сценариев Docker прошли.
- [live.json](live.json) — на обычном сервере и Qwen результат ok, одна подтверждённая
  запись, changed остался на диске после закрытия. Для повтора через окно
  запустить `make up`, затем `make gui`, выбрать папку с note.txt и текстом
  original, подключиться и отправить «Прочитай note.txt через read_file.
  Замени original на changed с помощью write_file. Заверши задачу».
  Подтверждалась только запись в синтетический note.txt.

Путь к выбранной папке и ключи в результатах отсутствуют. Windows и удалённый
Docker-хост требуют отдельных проверок. [Архитектура](../../docs/adr/0010-local-workdir.md).
