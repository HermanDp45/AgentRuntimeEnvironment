# Локальная подготовка к ЧП2

2026-11-11, macOS arm64 + Docker Desktop. Проверяющий — агент; человеческая
проверка не проводилась. Используются только синтетические папки и fixture-model.

## Воспроизведение

```bash
make setup-gui
make test-ci
```

Полный CI включает unit, отдельный Compose, инфраструктуру, mock UI,
Б1–Б8 + Б9.1–Б9.3 через сценарный replay, перезапуск менеджера и очистку.
Для нагрузочных проверок нужны cgroup v2 и хотя бы два CPU Docker VM.
Образы и зависимости должны быть подготовлены; при первой сборке нужен registry.
Тестовые запросы не обращаются к внешней модели.

Исходная конфигурация: services/sandbox-manager/config.toml,
tests/infra/compose.yml и services/llm-proxy/testing/baf_replay.json.
Ответы replay написаны вручную. Их успех не означает качество реальной LLM.

`failed-ci.txt` сохраняет промежуточный отказ: пустой Bearer-заголовок внутреннего
клиента скрытых тестов. Исправлен отдельным клиентом без авторизации менеджера.
Проверка PID затем облегчена: вместо 128 Python-интерпретаторов запускаются
ограниченные fork-потомки с гарантированным завершением и сбором.

Скрытые проверки требуют не только exit 0, но и JUnit-отчёт с ожидаемыми тестами.
Неверная функция и os._exit(0) должны отклоняться. Сбой скрытой проверки всегда
сбрасывает pass, даже если файловый чекер уже сообщил успех.

Проверка разных машин, Windows, запись cp1251, падение харнеса в ходе команды,
полный набор курса и реальные модельные прогоны остаются открытыми.

## Временная папка через mount

```bash
make up-test
BAF_ARGS='--mount --task B9.3 --repeat 2 --output results/2026-11-11-c2-local/mount.jsonl' make baf-smoke
make down-test
```

Оба повтора прошли: [JSONL](mount.jsonl), [полный лог](mount.txt).
Каждый использовал новую временную папку, session.create, WebDAV/NFS и подтверждённый
WriteFile. Закрытие сессии и остановка Compose успешны. При повторном воспроизведении
задайте новый output: раннер не перезаписывает исходные результаты.
