# Наш харнес и DeepSeek V4.1 Flash 1017

Прогон от 18 ноября 2026 года на Mac с Docker Desktop, версия проекта
`cdf9b09df6d9d4d9bd5e4f7cb49d5bb1fbeccbd8`. Модель курса
`deepseek-ai/DeepSeek-V4.1-Flash-1017`, шлюз `https://litellm-backend.deeppavlov.ai`.
Харнес передавал temperature=0 и max_tokens=1024. Reasoning effort определял шлюз.
Параметры харнеса и сандбокса закреплены в TOML, хеши входов — в манифестах.

Сначала раннер выполнил пробную B1.1. Затем три независимых процесса раннера
выполнили по одному проходу полного набора. У каждого запуска задачи собственная
временная папка, смонтированная через WebDAV/rclone, и отдельная сессия. Время
задачи включает локальное монтирование, инструменты, ожидание модели, проверки
и закрытие сессии при одновременной работе трёх процессов.

Для повторения из корня проекта с подготовленным Docker Desktop и виртуальным окружением:

```bash
.venv/bin/python results/2026-11-18-deepseek-full/reproduce.py results/deepseek-repeat
```

Команда запросит ключ скрытым вводом. Нужны свободные локальные порты 19880 и 19881.
Исходные строки каждого прохода — `round-1.jsonl`, `round-2.jsonl`, `round-3.jsonl`.
Номер прохода указан в имени файла. Каждый процесс запускался с одним повтором,
поэтому внутри исходной строки его локальный счётчик repeat равен 1. Пробная задача
сохранена отдельно в `pilot.jsonl`.

Все 117 записей содержат идентификатор ожидаемой модели. Итог по проходам —
32/39, 28/39 и 30/39. Всего 90/117 (76,9%). 27 задач прошли трижды, семь
провалились во всех повторах, у пяти исход менялся. Чекеры отклонили 26 попыток,
B6.3 один раз завершилась по таймауту. Медиана времени попытки составила 34,599 с.
Учтено 759179 входных и 76886 выходных токенов по полученным событиям харнеса.

Объединить результаты и рассчитать метрики из корня проекта:

```bash
python3 results/2026-11-18-deepseek-full/summarize.py results/2026-11-18-deepseek-full
```

Скрипт сверяет манифесты, список задач, повторы и уникальность запусков.
В full.jsonl номер повтора соответствует номеру прохода, в summary.json
приведены успехи по каждому проходу, исходы, время и токены по группам.
