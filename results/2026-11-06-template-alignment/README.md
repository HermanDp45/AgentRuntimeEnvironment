## Проверка запуска

Среда: Mac arm64, Python 3.13.15, uv 0.12.12, Docker Desktop с Linux-контейнерами.
До и после переноса `make test-ci` и Compose прошли; HTTP-ответ сохранился.

```bash
make setup
make test-ci
make up
curl --fail http://127.0.0.1:8080/health
make down
make run
# В другом терминале:
curl --fail http://127.0.0.1:8080/health
# Остановка локального сервера — Ctrl+C.
```

Compose получил healthy, gateway работает от UID 10001, LLM_API_KEY отсутствует
в его окружении. После `make down` контейнер и сеть удалены.
Исходный вывод unit-проверок — [test-ci.txt](test-ci.txt), запусков — [launch.txt](launch.txt).
