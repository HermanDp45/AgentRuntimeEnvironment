# Результаты

Здесь хранятся реальные результаты прогонов и замеров. Пока прогонов БАФ нет.
Не добавляйте вымышленные числа и файлы, изображающие завершённый эксперимент.

Для БАФ используем путь шаблона: `baf/<pair>/<timestamp>.jsonl` внутри `results/`.
Поля строки: `task_id, repeat, pass, reason, tokens_in, tokens_out, seconds, outcome`.
Рядом сохраняются конфигурация и команда воспроизведения; итоговый разбор — в `docs/report.md`.

Проверки подготовки и разовые замеры могут использовать каталог `YYYY-MM-DD-name/`.
Для каждого эксперимента сохраняются:

- `README.md`: цель, точная команда воспроизведения, ревизия кода,
  версии компонентов и условия запуска;
- конфигурация с идентификаторами харнеса и модели, версиями и лимитами;
- сырые JSONL/CSV: задачи, повторы, исходы, длительности, токены и ошибки;
- очищенные трассы и отчёт, если они нужны для объяснения результата.

Для замеров фиксируйте единицы, число повторов, ОС, архитектуру,
выделенные ресурсы и сетевые условия. Медиана и p95 считаются из сохранённых данных.
Скрипт или команда построения каждой итоговой цифры указывается в README проекта.

Перед коммитом удаляйте ключи, заголовки авторизации, персональные данные
и содержимое пользовательских папок. Используйте специально подготовленные фикстуры.
Результаты и их конфигурации коммитятся; весь каталог `results/` не игнорируется.
Веса и большие бинарники без LFS хранятся отдельно; рядом с отчётом укажите
их назначение, место получения и контрольную сумму.
