# UI-тесты

```bash
make setup-gui
make test-ui
```

QtTest нажимает кнопки настоящего окна PySide6. Управляемый HTTP/SSE-транспорт
заменяет сервер: нет Docker, API-ключа и внешних запросов. Проверяются diff до записи,
разрешение/отказ, повторное сообщение в той же сессии, отмена, возобновление SSE
без повторного task, ошибка авторизации и повтор закрытия после HTTP-ошибки.
QT_QPA_PLATFORM=offscreen позволяет выполнять проверки без экрана.

Два дополнительных теста используют окно Qt, настоящий gateway и контейнер сессии. В первом проверяются запись и команда на фикстуре. Во втором Qt выбирает временную папку, показывает diff и сохраняет подтверждённую правку на Mac. Запуск на Docker Desktop:

```bash
make setup-gui
HARNESS_TEST_URL=http://127.0.0.1:18080 make test-ci
```

Обычный Linux CI выполняет `make setup-gui` и `make test-ci`. Без `HARNESS_TEST_URL` два сквозных UI-теста пропускаются.
