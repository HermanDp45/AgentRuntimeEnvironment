# UI-тесты

```bash
make setup-gui
make test-ui
```

QtTest нажимает кнопки настоящего окна PySide6. Управляемый HTTP/SSE-транспорт
заменяет сервер: нет Docker, API-ключа и внешних запросов. Проверяются diff до записи,
разрешение/отказ, повторное сообщение в той же сессии, отмена, возобновление SSE
без повторного task, ошибка авторизации и повтор закрытия после HTTP-ошибки.
QT_QPA_PLATFORM=offscreen позволяет выполнять проверки без экрана.

Дополнительный сквозной тест окна с настоящим HTTP и Docker:

```bash
make setup
make setup-gui
make up-test
HARNESS_TEST_URL=http://127.0.0.1:18080 make test-ui
make down-test
```

Он использует mock LLM и fixture-client-token, отдельно подтверждает запись
и команду, проверяет файлы/вывод и закрывает сессию. Без HARNESS_TEST_URL пропускается.

Группа gui не обязательна для серверных тестов: make test-ci пропускает модуль,
если PySide6 не установлен. В CI отдельная задача gui устанавливает Qt и выполняет
make test-ui. Выбор/монтирование папки, восстановление после падения процесса
и полный headless-клиент ещё предстоят; C2-05 целиком не закрыта.
