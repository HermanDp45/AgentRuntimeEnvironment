# Инфраструктурные тесты

Сейчас реализован прямой HTTP-тест менеджера с настоящим Docker-сандбоксом:
файлы, повторы, SSE, Unicode, отмена дерева процессов, timeout, read-only,
сеть, размер /work, вывод, независимые сессии и release.

```bash
make up
make test-infra
uv run --frozen --offline python tests/infra/check_lifecycle.py
make down
```

Последний Python-скрипт проверяет аварийный перезапуск и штатную очистку локального
Compose без чужих активных сессий; оставляет менеджер остановленным.
Тесты используют синтетические файлы. Для уже установленных зависимостей и собранных
образов внешняя сеть не нужна. `make test-ci` пропускает HTTP-тесты, если не задан
SANDBOX_TEST_URL; `make test-infra` определяет адрес через Compose и требует его запуска.

Следующий объём C2-05: mock LLM и полный агентный сценарий, сбои харнеса и mount,
переподключение клиента, разрешённая сеть, canary-секрет, fork bomb и измерение
поведения CPU/RAM. Наличие текущих тестов не закрывает этот объём.
