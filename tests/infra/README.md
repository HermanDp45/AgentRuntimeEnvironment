# Инфраструктурные тесты

Статус: не реализованы. Здесь будут сценарии с mock LLM без внешней сети.
Текущий HTTP-тест gateway находится в `tests/unit/` и не считается проверкой инфраструктуры.

| Группа | Проверки |
|---|---|
| Контракты | Оба протокола валидны по схемам, проверены граничные случаи |
| Инварианты | Один result, идемпотентность, cancel дерева процессов, таймауты, граница секретов |
| Лимиты и очистка | CPU, RAM, PIDs, диск, время; нет оставшихся процессов и ресурсов |
| Изоляция | Выход за workdir, симлинки, canary-секрет, fork bomb, заполнение диска, запись в ro |
| Сеть | Разрешённое доступно, запрещённое блокируется; тестовые allowed-http и blocked-http |
| Сбои | Обрыв mount и клиента, падение харнеса посреди команды, ретраи |
| Сессии | Продолжение в новой сессии, независимые параллельные сессии |
| Синхронизация | Двусторонние правки, конфликт записи, поведение после восстановления mount |

`make test-infra` пока завершается ошибкой «не реализовано». Реализация — задача C2-05
в [TASKS.md](../../TASKS.md); конфликты и сбои должны соответствовать принятым ADR.
