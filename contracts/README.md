# Контракты

Статус: схемы ещё не реализованы. `/health` не заменяет ни один из двух протоколов A-6.

| Планируемый файл | Протокол |
|---|---|
| `client-server.v0.schema.json` | Подключение, сессия, сообщение, события, отмена, переподключение |
| `harness-sandbox.v0.schema.json` | provision, exec (RunCommand / ReadFile / WriteFile), events, ровно один result, collect, release/cancel |

Сообщения должны содержать версию. Ошибки различают ошибку команды, таймаут,
ошибку сандбокса и сбой транспорта; для каждого класса нужна политика ретраев.
Инварианты: идемпотентность, один финальный result, отмена дерева процессов,
таймаут каждой операции, отсутствие секретов за границей сандбокса.

Для обоих контрактов выбран HTTP/JSON для команд и SSE для событий —
[ADR-0006](../docs/adr/0006-http-sse.md). Сандбокс живёт активную сессию —
[ADR-0005](../docs/adr/0005-sandbox-session.md). Схемы и код пока отсутствуют.
Проверки — в [tests/infra/](../tests/infra/README.md).
Задача C1-03 — в [TASKS.md](../TASKS.md).
