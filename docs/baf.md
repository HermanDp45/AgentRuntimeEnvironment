# Набор БАФ

39 задач: 24 курсовые атомарные, 3 курсовые составные, 8 своих вариантов,
3 задачи новой Б9 и одна своя составная C4. Фикстуры находятся в baf/, эталоны и
скрытые тесты — рядом с ними, вне workdir. Автоматические чекеры исполняются на
хосте только как доверенный код; код кандидата запускается в отдельном сандбоксе.

## Свои варианты Б1–Б8

- Б1.4: извлечь срок хранения резервных копий среди разных сроков. Проверяется
  извлечение одного факта, а не рассуждение о политике или инфраструктура.
- Б2.4: найти реальное чтение TOKEN, отличив его от комментария. Проверяется
  локализация нужного места в нескольких исходниках.
- Б3.4: создать JSON с false, 0 и строкой "null". Проверяется точное создание
  структурированного файла с сохранением типов.
- Б4.4: изменить timeout только в prod-секции INI. Проверяется локальная правка
  при одинаковых значениях в других секциях; остальное сохраняется байт-в-байт.
- Б5.4: вызвать status.py и извлечь status из stdout при предупреждении в stderr.
  Требуется реальный вызов инструмента с ожидаемым exit code, не догадка по файлу.
- Б6.4: написать clamp, включая совпадающие и неверно упорядоченные границы.
  Проверяется генерация функции скрытыми тестами, без дополнительного поиска.
- Б7.4: выбрать слот по ограничениям и отсутствующему допуску. Проверяется
  применение правил к заданным фактам.
- Б8.4: связать пользователей и покупки по id, включая пользователей без покупок.
  Ответ требует совместить два источника, а не прочитать готовую сумму.

Каждый вариант изолирует одну функцию агента. Сессии, сеть, лимиты, монтирование
и восстановление проверяются инфраструктурным набором, не этими задачами.

## Новая Б9: нормализация таблиц

Выбрана пользователем. Это преобразование представления таблицы по заданной схеме:

- Б9.1: пробелы и целые количества.
- Б9.2: русские даты и денежные суммы → ISO и целые копейки.
- Б9.3: неоднозначные даты и отрицательные количества → отчёт ошибок,
  без молчаливого исправления или потери строки.

Данные уже найдены и находятся в одном источнике, агрегировать разные документы
не нужно. Это отличает Б9 от поиска Б2 и синтеза Б8. Чекер проверяет все значения,
типы JSON, порядок, номера ошибочных строк и неизменность исходного CSV.

## Составные задачи

- C1: Б2 → Б1 → Б7 → Б4 → Б5. Найти average, прочитать issue и код, определить
  причину, исправить функцию и запустить публичный тест; скрытые тесты независимы.
- C2: Б2 → Б8 → Б7 → Б3. Найти входные данные отдела, совместить выручку и расходы,
  вычислить прибыль, записать отчёт с проверяемыми числами.
- C3: Б1 → Б6 → Б5 → Б4. Прочитать спецификацию, добавить утилиту с тестами,
  выполнить их и обновить README. Скрытая проверка дополнительно требует, чтобы
  тесты кандидата отвергали намеренно сломанную утилиту, а не только assert True.
- Своя C4: Б1 → Б9 → Б7 → Б3. Прочитать сырую таблицу, нормализовать суммы и
  выделить неоднозначные строки, посчитать итог допустимых сумм, записать таблицу
  и отчёт. Ошибка нормализации меняет итог и число отвергнутых строк, поэтому
  результат можно разбирать по отдельным этапам цепочки.
