# Как агент меняет файл

Возьмём запрос «Замени original на changed в note.txt». В проверенном сценарии папка находится на Mac, Docker работает через Docker Desktop на том же компьютере.

1. **Клиент открывает сессию.** После выбора папки Qt запускает WebDAV-экспорт со случайным токеном. Клиент отправляет запрос создания сессии через gateway. Экспорт ограничивает доступ выбранным каталогом и скрывает защищённые пути. [Окно чата](../client/gui.py) · [Экспорт папки](../client/workdir.py) · [Gateway](../services/gateway/src/agent_runtime/gateway.py)
2. **Менеджер готовит рабочую папку.** Отдельный процесс rclone читает экспорт и предоставляет Docker том NFS. Менеджер создаёт контейнер сессии и монтирует том в `/work` только для чтения. У контейнера агента отключена сеть. [Монтирование](../services/sandbox-manager/src/sandbox_manager/workdir.py) · [Создание контейнера](../services/sandbox-manager/src/sandbox_manager/backend.py)
3. **Харнес получает решение модели.** Он отправляет историю и описания инструментов через LLM-прокси. При вызове чтения харнес обращается к менеджеру, получает текст и возвращает результат модели. Модель может вызвать следующий инструмент или дать ответ. [Агентный цикл](../services/harness/src/agent_harness/loop.py) · [Прокси](../services/llm-proxy/src/llm_proxy/app.py)
4. **Пользователь подтверждает правку.** Чат показывает diff. После разрешения менеджер передаёт новые байты и ожидаемый SHA-256 клиентскому экспорту. Если пользователь успел изменить файл на Mac, экспорт отклоняет устаревшую запись. Команды shell также требуют разрешения и могут читать смонтированную папку. [Инструменты](../services/harness/src/agent_harness/tools.py) · [Протоколы](../contracts/README.md)
5. **Клиент получает результат.** События и вывод команды приходят по SSE. При закрытии сессии менеджер освобождает контейнер, том, помощник и сеть, а клиент закрывает экспорт. Изменённый файл остаётся на Mac. [Тест с выбранной папкой](../tests/ui/test_chat.py)

## Где начинается удалённый сценарий

При работе с отдельным сервером Docker видит файловую систему Linux. Чтобы тот же агент увидел папку Mac, серверу нужен канал до клиентского экспорта. В эксперименте SSH передал запросы WebDAV между двумя машинами, включая запись обратно и отказ при конфликте версий. В штатном клиенте выбранная папка пока подключается только к локальному gateway. Открытый критерий — пройти все пять шагов выше через удалённый сандбокс и проверить поведение при обрыве. [Эксперимент](../results/2026-11-15-readiness/README.md) · [Предложение по удалённому монтированию](adr/0002-workdir-mount.md)

## Как проверяется результат

`make test-ci` проверяет сервисы и изоляцию с предсказуемыми ответами mock LLM. Раннер БАФ измеряет работу пары «харнес + модель» на фиксированных заданиях: для каждой попытки создаёт чистую сессию, применяет правила подтверждения и запускает чекер. Наша дополнительная функция Б9 проверяет нормализацию таблиц. [Описание задач](baf.md) · [Результаты DeepSeek](report.md)
