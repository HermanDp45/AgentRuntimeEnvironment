# ADR-0005: сандбокс на активную сессию

- Статус: accepted для учебного сандбокса v0; монтирование и долговечность данных — следующий этап
- Дата: 2026-11-06

## Контекст

Чат содержит несколько задач, которым нужна одна рабочая папка и предсказуемое
окружение. Студент выбрал контейнер на активную сессию чата.

## Решение

Согласовано: сандбокс сохраняется между задачами активной сессии. Завершение
сессии освобождает контейнер; рабочая папка пользователя не удаляется.
Новый прогон БАФ получает чистую сессию и фикстуру.

Реализовано в прототипе: Python, shell и pytest, непривилегированный пользователь,
read-only root, запись в /work и ограниченный /tmp, сеть по умолчанию закрыта.
Ключ провайдера и Docker socket не передаются в сандбокс.
Начальные ограничения — 1 CPU, 1 ГБ RAM и очистка после 30 минут простоя;
значения подключены в services/sandbox-manager/config.toml; детали — ADR-0007.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Новый контейнер на каждую задачу | Чистое временное состояние | Сброс окружения между сообщениями, повторная подготовка | Студент выбрал активную сессию |
| Один общий контейнер для всех чатов | Меньше контейнеров | Сессии влияют друг на друга | Требуется разделение сессий |

## Последствия

Нужны явное завершение сессии, очистка ресурсов и определённое поведение после сбоя.
Один контейнер на чат не означает сохранение окружения после его удаления.
Срок хранения истории и копий пользовательских данных должен соответствовать A-3.5.

Локальный запуск, права доверенного менеджера и реальный лимит tmpfs проверены
и описаны в [ADR-0007](0007-sandbox-v0.md). Способ запуска на демонстрационной
Linux-машине ещё предстоит подтвердить, сравнив с rootless Docker.

Проверено агентом: повторные операции, параллельные сессии, отмена дерева процессов,
release, idle (ускоренный unit-тест), read-only, очистка после перезапуска и shutdown.
[Результаты v0](../../results/2026-11-06-sandbox-v0/README.md). Временная /work удаляется
с контейнером; согласованное сохранение пользовательской папки требует будущего mount.
