# 0001. Основа проекта

Дата: 2026-11-04. Статус: принято.

## Контекст

Репозиторий начинается с нуля. Нужны воспроизводимый запуск и небольшой код,
который студент сможет объяснить. На первом этапе нет доступа к API модели
и отдельного Linux-сервера.

## Решение

Python 3.13.15, uv 0.12.12 и один lock-файл. Первый сервис — gateway на FastAPI
с HTTP-проверкой доступности. Проверки — pytest и Ruff; Docker и CI используют
закреплённые версии. Python-код лежит в одном пакете `src/agent_runtime`.

Сейчас собираем один сервис. Границы харнеса, proxy и менеджера выделяем
по мере появления работающих сценариев. Десктоп-клиент позже — на PySide6;
сейчас эта зависимость не устанавливается.

## Альтернативы

- Python + Electron: удобен для веб-интерфейса, но добавляет второй стек и сборку.
- Готовый большой агентный фреймворк с начала проекта: ускоряет отдельные функции,
  но усложняет разбор собственного цикла на защите.
- Все сервисы сразу по шаблону курса: создаёт заглушки без проверяемого поведения.

## Последствия и проверка

Минимальный запуск не требует модели и не доказывает готовность полного сервера.
Общий пакет упрощает старт; он не отменяет будущих протокольных границ.
Выбор PySide6 согласован со студентом, но сборка клиента пока не проверена.
Основа проверяется установкой по lock-файлу, `make test-ci` и реальным запуском Compose.
