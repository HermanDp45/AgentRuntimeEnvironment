# ADR-0010. Выбранная папка в локальном чате

Дата 2026-11-11. Статус accepted для локального Docker Desktop на macOS.
Связано с ADR-0002, ADR-0007 и ADR-0009.

## Решение

Пользователь выбирает каталог в Qt и подключает его к локальному gateway.
Клиент открывает выбранный каталог через POSIX-дескриптор и запускает локальный
WebDAV-экспорт с одноразовым Bearer-токеном. Операции проходят через дескрипторы
каталогов и O_NOFOLLOW. .git, .env, симлинки и файлы с несколькими жёсткими
ссылками скрыты. Изменения записываются через временный файл и проверку SHA.

Менеджер создаёт отдельную Docker-сеть и доверенный rclone-помощник. Помощник
читает WebDAV через host-gateway и предоставляет NFSv3 для тома Docker.
У сандбокса остаются network=none, cap-drop ALL и read-only root. Его /work
подключён только для чтения. Для подтверждённого WriteFile менеджер передаёт
запись клиентскому экспорту с ожидаемым SHA. Команды могут читать /work,
создавать и запускать временный код в /tmp. Для изменения рабочей папки
модель использует write_file.

Вспомогательная NFS-служба доступна внутри отдельной сети без публикации порта
на хост. Папка не копируется на сервер. В tmpfs помощника хранятся только
NFS-дескрипторы. Перед чтением и сбором файлов обновляется дерево VFS через
контрольный порт на loopback помощника. Нулевой dir-cache-time давал stale
file handle, поэтому обновление выполняется явно.

При закрытии сессии менеджер удаляет сандбокс, сетевой том, помощник и сеть,
затем клиент останавливает экспорт. Файлы пользователя сохраняются.
При следующем запуске менеджер также очищает оставшиеся ресурсы своего namespace.

## Альтернативы

- FUSE на отдельном Linux-хосте уже проверен в ADR-0002. Для Linux Docker Desktop
  передача mount между контейнерами требует дополнительной инфраструктуры.
- FUSE внутри сандбокса потребовал бы привилегий для монтирования.
- Запись команд через кеш NFS потребовала бы дополнительных правил публикации,
  ошибок и подтверждения. Выбрана явная запись через существующий WriteFile.

## Границы и проверка

Это локальное подключение, когда GUI и Docker daemon находятся на одном компьютере.
Туннель для удалённого сервера остаётся отдельным экспериментом ADR-0002.
Экспорт реализован для POSIX. На Windows нужна реализация безопасных операций
через файловые дескрипторы Windows. Ограничения текущего просмотра — до 128
текстовых файлов размером до 64 КиБ.

Проверено агентом через Qt, gateway и настоящий Docker с mock LLM.
Выбор каталога, видимость файлов, подтверждение, запись на диск и изменение
с клиента прошли. Исходные файлы сохраняются после закрытия.
Unit-тесты проверяют авторизацию, закрытые пути, симлинки, жёсткие ссылки,
проверку SHA и Range-чтение. [Результаты](../../results/2026-11-11-selected-folder/README.md).
