# ADR-0014. Выбор модели для нового чата

18 ноября 2026. Принято для Qt-клиента и серверного прокси. Дополняет ADR-0008.

Ранее смена модели требовала пересоздания прокси и затрагивала все сессии. Пользователь выбрал переключение из окна или при запуске из терминала. Клиент отправляет имя профиля при создании чата. Харнес запоминает выбор вместе с сессией, прокси сопоставляет профиль с адресом API, моделью и ключом. Клиенты без профиля продолжают использовать конфигурацию сервера.

Смена модели посреди истории смешивала бы ответы двух моделей в одной сессии. «Новый чат» освобождает прежний сандбокс и позволяет выбрать модель для новой переписки. Ключи остаются у прокси. В журнале отображается идентификатор из ответа API.

Проверено на двух одновременных сессиях с реальными DeepSeek и Qwen. Qt-тест проверяет передачу выбора, тест прокси — разделение ключей. При отсутствии ключа запрос отклоняется.
