# Архитектурные решения

- [0001. Основа проекта](0001-project-foundation.md) — принято.
- [0002. Монтирование workdir](0002-workdir-mount.md) — предложено, нужен эксперимент.

Новый ADR получает последовательный номер и содержит дату, статус, контекст,
решение, альтернативы, последствия и способ проверки. Принятое решение должно
опираться на проверку. При замене старый документ остаётся со статусом
`superseded` и ссылкой на замену.

По мере реализации добавим ADR про харнес, сандбокс и его запуск,
оба транспорта, модель сессий, сетевую политику и выбор пары по БАФ.
