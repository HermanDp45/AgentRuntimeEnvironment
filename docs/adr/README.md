ADR-0004–0006 имеют статус proposed до проверки реализации. Согласованные в них
решения отражают ответы студента; повторно выбирать их без причины не требуется.

Новый ADR получает последовательный номер и содержит дату, статус, контекст,
решение, альтернативы, последствия и способ проверки. Принятое решение должно
опираться на проверку. При замене старый документ остаётся со статусом
`superseded` и ссылкой на замену.
