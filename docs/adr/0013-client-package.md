# ADR-0013. Локальная сборка настольного клиента

Дата: 2026-11-11. Статус: accepted для macOS arm64. Связано: ADR-0009, C2-04.

## Решение

Существующий PySide6-клиент собирается PyInstaller 6.16.0 в onedir .app.
Зависимость находится в отдельной группе packaging и uv.lock, не в серверном
runtime. Точка входа — client/desktop.py, команда — make build-client.
Артефакт dist/AgentRuntime.app исключён из Git. Проверка --smoke-test создаёт
и штатно закрывает настоящее окно Qt в offscreen-режиме.

## Альтернативы и последствия

- Запуск из uv: остаётся для разработки, но требует Python-окружения у пользователя.
- onefile: добавляет распаковку при каждом старте; для учебной демонстрации не нужен.
- Другой GUI-стек: не оправдан, существующий Qt-клиент уже проверен.

Сборка предназначена для локальной демонстрации. PyInstaller выполняет ad-hoc
подпись; notarization и распространение другим пользователям не проверены.
Windows и Linux требуют нативной сборки и отдельной проверки. Локальный тест
сборки не доказывает удалённое подключение или работу на чужой машине.

[Параметры PyInstaller 6.16.0](https://pyinstaller.org/en/v6.16.0/usage.html).
