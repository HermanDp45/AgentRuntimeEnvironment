# ADR-0003: структура по шаблону курса

- Статус: accepted
- Дата: 2026-11-06

## Контекст

Первоначальная основа хранила gateway в корневой `src/` и не содержала всех файлов
официального шаблона. Студент потребовал структуру и формат шаблона задания A.

## Решение

Сохранить Python 3.13.15, uv 0.12.12 и общий lock-файл. Исходники и Dockerfile gateway
перенести в `services/gateway/`, Compose назвать `docker-compose.yml`.
Docker build context остаётся корневым для доступа к общему lock-файлу.
Восстановить все пути шаблона, формат README, документов, БАФ и команд Makefile.
Нереализованные компоненты содержат только описание статуса; в Compose включён gateway.
Не переносить фиктивные healthcheck и успешные TODO-команды из заготовки.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Оставить корневую src/ | Меньше перемещений | Не соответствует запросу и шаблону | Требуется структура курса |
| Отдельный lock-файл на каждый сервис | Независимые зависимости | Дублирование среды до появления компонентов | Пока один реализованный сервис |
| Скопировать заготовку Compose целиком | Совпадает внешне | Несуществующие сборки, CMD true, передача общего .env | Нужен рабочий и честный запуск |

## Последствия

Импорт `agent_runtime.gateway:app`, HTTP-контракт и порт сохраняются.
Меняются пути исходников и Dockerfile; старые результаты остаются историческими.
Сторонние фикстуры и чекер сохраняются без форматирования по закреплённой ревизии.
Проверки: `make test-ci`, оба запуска, сравнение файлов шаблона и проверка чекера Б1.1.
