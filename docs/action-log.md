## 2026-11-04 — среда, gateway и CI

**Зачем.** Получить небольшой работающий запуск без ключа модели и проверять
каждое последующее изменение в закреплённой среде.

**Изменено.** Python 3.13.15 в локальном кеше проекта, uv.lock, FastAPI gateway,
Makefile, Dockerfile, Compose, HTTP-тест и GitHub Actions. Docker Desktop запущен
для контейнерных проверок. Системный Python не менялся. Dev-зависимость httpx2
выбрана по требованиям установленной Starlette, чтобы убрать её deprecated-режим.
Кеши, `.env` и окружение исключены из Git; Docker получает только исходники и lock-файл.

**Проверка.** Агент: `make setup`, повторная установка с изменённым локальным `.env`
(содержимое сохранено), согласованность lock-файла, Ruff, pytest (1 тест),
`make run` и HTTP-ответ. Compose собран с финальным lock-файлом, перешёл в healthy;
проверены UID 10001, отсутствие capabilities, no-new-privileges и read-only root.
После `docker compose down -v --remove-orphans` контейнер и сеть удалены.
Локальный процесс также остановлен. Это проверки gateway, не доказательство
изоляции будущего сандбокса. [Исходные выводы и условия](../results/2026-11-04-bootstrap/README.md).

Удалённый CI и публикация проверяются после создания коммитов.
