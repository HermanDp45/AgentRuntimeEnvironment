## 2026-11-06 — первый харнес, подтверждения и LLM-прокси

**Зачем.** Подключить существующий сандбокс к согласованному собственному циклу.
Студент выбрал завершение текстом без tool_calls, без отдельного finish_task.

**Изменено.** В services/harness/ добавлены последовательный цикл, история,
валидация трёх инструментов, свежий SHA/diff перед approval, лимиты и HTTP-клиенты.
Сессии принимают один запуск, повтор task не вызывает модель заново; повтор approval
не меняет решение. Потеря POST/SSE восстанавливает наблюдение по прежнему operation_id,
а неподтверждённая отмена блокирует сессию и возвращает transport, не cancelled.
Менеджер теперь освобождает session.busy и публикует result под одним lock: следующий
инструмент не попадает в промежуток завершения и не получает случайный session_busy.

LLM-прокси хранит ключ, добавляет model/Authorization, проверяет TLS и не пересылает
тела ошибок провайдера. Gateway проверяет клиентский Bearer-токен и передаёт HTTP/SSE.
Консоль показывает diff/команду, запрашивает отдельное решение для каждого действия,
принимает Ctrl+C и закрывает учебную сессию. Настоящая папка Mac не подключалась.
JSONL-метаданные находятся в приватной tmpfs, без текстов и команд; удаляются при close.
httpx2 перенесён из dev в runtime-зависимости без смены версии и добавления новой библиотеки.
Добавлены ADR-0008, обновлены ADR-0004/0006, карта кода и команды README.

**Проверка.** Агент: make test-ci — lock/Ruff, 42 passed, 9 явно пропущенных
